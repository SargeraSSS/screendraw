# screendraw

Transparent Wayland overlay for drawing on top of the screen with the mouse.

Requires Python 3, PyGObject, GTK4 and gtk4-layer-shell.

Run `./screendraw`. Running it again closes the overlay.

| Input | Action |
| --- | --- |
| LMB | draw |
| RMB | erase stroke |
| 1-7 | color |
| Wheel, `+`, `-` | width |
| Ctrl+Z, `U` | undo |
| `C` | clear all |
| Esc, `Q` | quit |
